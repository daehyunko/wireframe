    3. 치환번역 예시 : [애플 파이] > [ABCD] 등록 시 [애플 파이] -> [ABCD] 로 번역 후 [파이 애플] 은 번역 안함.
    4. 조합 + 치환번역 예시 : [애플] > [apple], [파이] > [pie], [애플 파이] > [ABCD] 등록 시 [애플 파이] -> [ABCD] 로 치환번역 우선 적용 후 [파이 애플] -> [pie apple] 로 조합번역.
    5. [글로딕 기본단어 확인] 에서 기본단어를 복사 후 원하는 언어로 수정이 가능.
